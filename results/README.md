## 如何阅读

- E09/E10/E11/E12及R04历史对照使用当时的数值配置；R07/R08的FP32直接作答before是64/161，不替换历史BF16的65/161。
- `strict_matches`/`correct`是严格终值命中，不是完整推理认证。`successful_tool_requests`只说明执行器成功。
- R08使用自动终值1/0奖励；R04/R07使用逐轨迹过程审核，奖励口径不同。
- R08主比较固定round64。两组before一致；题级配对统计只作描述，单训练seed且未做多重比较校正。
- 原`rl_train_seen/unseen`分组保留R07历史命名；这24题全部排除于R08训练。`tool_holdout`曾见过E09普通SFT短解，只对工具SFT留出。
- 汇总值来自本地已复核结果；未在整理此仓库时重训或重新评分。逐token证据、完整轨迹、优化器及原始压缩包留在本地。
- 仅凭本精简仓库无法完整重跑训练，不把配置摘录当作可执行训练包。
